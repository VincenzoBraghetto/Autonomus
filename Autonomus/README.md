<h1 style="text-align: center;"> Autonomus </h1>

![Autonomus Screenshot](./resources/AutonomusScreenshot.png)

Autonomus is an automatic metronome that increases or decreases beats per minute automatically based on the selected start BPM, end BPM and how fast the tempo changes.

## How to use

The app features the following controls:

- **Play:** plays or stops the metronome. The LED light at the center of the app will flash everytime the click is triggered.

- **Freeze BPM:** this setting freezes the BPM and keeps it constant, making it a normal metronome. You can unfreeze the tempo at anytime and it will continue where it left.

- **Current BPM:** shows the current tempo and also functions as the starting point for the metronome.

- **End BPM:** the tempo that the metronome will stop at. You can set it to a value below the current BPM too.

- **Seconds per new beat:** the amount of seconds it takes too add or sustract a beat from the current BPM (for example, seconds per new beat at 0.5 is equivalent to increasing the tempo by 2 every second).
